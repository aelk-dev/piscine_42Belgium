
# 42 Piscine

## About

This repository contains the projects and exercises completed during the 42 School Piscine at 42 Belgium in July 2026.

The Piscine is an intensive programming experience focused on learning programming fundamentals through hands-on challenges, independent research and peer-to-peer learning.

Throughout this experience, I worked on programming exercises and collaborative projects, mainly using C and shell scripting.
